# Plans (frontend-heavy features)

One folder per feature: `.claude/plans/<feature>/SPEC.md` (what, rules, out of scope, done means) and
`PLAN.md` (small steps, status, Problems log). A feature that is mostly backend lives in
`TraceMyMoneyAPI/.claude/plans/` instead (one plan, not two). See `CLAUDE.md`.

A plan with UI steps must start them with the approved design Artifact URL (see the skill
`build-ui-from-approved-draft`).
